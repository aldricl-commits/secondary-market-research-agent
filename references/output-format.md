# 输出格式与可读性规范

目标：深度不等于难读。机构研报的可读性来自**结论前置、信息分层、数字规范、视觉锚点**。撰写正文前必读本文件。

## 0. 报告开头三件套与 football field

**结论框**（标题下第一个元素）：一段引用块，包含一句话论点、结论标定（低估/合理/高估/显著高估）、公允价值区间 vs 现价与隐含空间、综合置信度（高/中/低）、1–2 个最近催化剂。读者只看这一框就能知道结论。

**Tearsheet**（结论框之后）：一张关键数据表——现价/市值/EV、核心倍数（当前 vs 历史中枢 vs 可比中位）、三情景每股价值与概率、共识评级分布与目标价中位、财报可信度等级、数据截止日。每行带来源。

**本章要点**：每章开头 2–4 条 bullet 先给该章结论，正文再展开论证。

**Football field**（估值章汇总处）：把各估值方法的区间画成横向条形对比图，加一条现价竖线。条目按 `valuation-methods.md` §4 的三种方法各画一条（情景加权 / 相对估值 / 永续 DCF），条上标出该方法的**概率加权中值**与所占权重；最后一条画方法加权后的综合区间。Markdown 报告用表格 + 区间条（如 `├──────┤`）或 mermaid 实现；条目 = 方法名 + 区间 + 中值，现价位置显式标出。区间不重叠时必须在正文归因。

## 1. 章节写法
- 段落 ≤5 行；超过就拆或改表格。连续 3 段没有数字的分析要警惕——多半是空话。
- 图表就近原则：表格紧跟引用它的论述，不集中堆在章末。

## 2. 数字规范

- **绝对额行必须配一行比率行**：多年财务表里，总收入下配 `% YoY`，毛利/经营利润/EBITDA/净利润下各配 `% margin`。只给绝对额等于把心算外包给读者，而趋势与利润率才是结论所在。
- 千分位分隔；货币符号 + billion简化为bn, million简化为mm；百分比保留 1 位小数，估值每股保留整数或 1 位。
- **精度匹配不确定性**：DCF 输出写 "$185–$240" 而不是 "$212.47"——假装精确是伪严谨。
- 同比/环比用 +/− 号；负数不用括号（中文语境）。
- 每张表格列出"来源/时间"列或表注。

## 3. 长度与密度纪律

- 深度 = 信息密度 × 覆盖完整性，不是字数。每章自查："删掉哪一段读者不受损失？"能删就删。
- 附录收纳原始数据长表；正文只放被论证使用的数字。

## 4. 置信度自评（正文最后一章末尾必附）

| 维度 | 评分（高/中/低） | 说明 |
|---|---|---|
| 数据完整度 | | 关键数据获取比例、Tier 1 覆盖率 |
| 估值收敛度 | | 多方法区间重叠程度 |
| 预期差清晰度 | | variant view 是否可证伪 |
| 财报可信度 | A/B/C/D | forensic 模块输出 |
| **综合置信度** | | 低置信度 + 好标签 ≠ 大仓位 |

## 5. 预测可追踪性

- 每条核心预测使用区间和明确验证日期，不使用“长期向好”之类无法到期判定的句子。
- 经营 KPI、催化剂路径、估值倍数与股价/总回报分开记录；股价方向错误不自动等于经营判断错误，反之亦然。
- 更新报告时保留旧预测和原时间戳，只追加实际结果、命中状态、误差归因和模型回写。
- 命中状态只使用：命中、部分命中、未命中、无法验证；“无法验证”必须解释缺失数据或事件延期。
- 英文报告使用 `Forecast register`、`Validation date`、`Hit / Partial hit / Miss / Not verifiable` 等价字段。
