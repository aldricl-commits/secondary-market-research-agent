# 财报质量与会计侦查手册（Forensic Accounting）

目的：在下任何"beat/miss"结论之前先回答一个问题——**这份财报的数字能不能信**。本手册被 `earnings-mode.md` §8 引用：每次财报必跑第 1 节最小核查集；首次覆盖或最小集报警时跑第 2–4 节；无论结果如何，第 5 节可信度等级必须落到第一章快照表，且其否决规则优先于估值结论。

原则：
- 单一指标恶化是线索不是判决；**多指标同向恶化**才升级。为什么：任何单项都可能有正当业务解释。
- 每项核查记录"数值 + 阈值 + 结论（过/恶化/严重）"，不许只写"大致正常"。为什么：不可检查的核查等于没做。
- 公司解释可以记录，但不能自动采信；采信须写明独立佐证。为什么：操纵者的解释永远比数字体面。

---

## 1. 最小核查集（每次财报必跑，5–10 分钟量级）

六项全查，缺数据的项标"未获取到 + 原因"，不许静默跳过。

| # | 核查项 | 公式 | 恶化阈值 | 意义（为什么查） |
|---|---|---|---|---|
| 1 | 应计比率 | (净利润 − OCF) ÷ 平均总资产，本季 + TTM 各算一次 | TTM > +5% 或本季环比恶化 > 3pct | 高应计 = 利润靠会计估计而非现金，是盈余操纵最强单一预测因子 |
| 2 | 现金转化 | OCF/净利润 与 FCF/净利润（TTM） | OCF/NI < 80%，或连续 2 季下滑 | 利润长期换不成现金，要么质量差要么在借未来 |
| 3 | 营运资本背离 | DSO=应收÷收入×90；DIO=存货÷COGS×90；DPO=应付÷COGS×90；对比同比 | DSO 同比增幅 − 收入同比增幅 > 10pct；DIO 同理 | 应收/存货跑得比收入快 = 塞货渠道或需求已断，收入确认在提前 |
| 4 | 递延收入/合同负债 | 合同负债同比增速 vs 收入同比增速（订阅/预收型公司必查） | 递延增速落后收入增速 > 10pct 且连续 2 季 | 递延是未来收入的蓄水池，池子先干、收入后崩 |
| 5 | Non-GAAP 调整项 | 逐项列出调整额、占税前利润比例、连续出现季数 | 单项连续 ≥4 季出现仍称"一次性"；调整总额 > GAAP 利润 50% | 经常性的"非经常项"是管理层自定义的第二套利润表 |
| 6 | 准备金计提率 | 坏账准备÷应收、存货跌价准备÷存货、保修/退货准备÷收入，环比+同比 | 计提率下降贡献了本季 beat 的主要部分 | 降准备金是零成本的利润调节阀，且必然透支未来 |

硬性规则：
1. 任何一项触发恶化阈值 → 写入报告第二章"业绩质量"**正文**，禁止放附注或省略。为什么：藏在附注等于替管理层打掩护。
2. ≥2 项恶化，或第 1/6 项单独严重（应计 TTM > +10%、准备金反向调节 > 本季利润 20%）→ 触发第 2 节扩展核查集。
3. 本节结果直接输入第 5 节评级，评级前不许写任何"业绩超预期"类定性结论。为什么：先验质量、后谈好坏，顺序反了会锚定。
4. 与预期差的联动：beat 的季度更要查——**低质量 beat（靠准备金、应计、一次性）必须在第二章明确标注"低质量超预期"**。

## 2. 扩展核查集（首次覆盖或最小集报警时）

### 2.1 Beneish M-Score 8 变量简表

M = −4.84 + 0.92×DSRI + 0.528×GMI + 0.404×AQI + 0.892×SGI + 0.115×DEPI − 0.172×SGAI + 4.679×TATA − 0.327×LVGI。**M > −1.78 视为操纵嫌疑区**；−2.22 至 −1.78 为灰区。

| 变量 | 含义 | 危险方向 |
|---|---|---|
| DSRI | 应收/收入指数（同比） | >1.03 应收增速超收入 |
| GMI | 毛利率指数（去年÷今年） | >1.01 毛利率恶化仍在扩张 |
| AQI | 资产质量指数（非流动非固定资产占比变化） | >1.04 软资产膨胀（资本化藏费用） |
| SGI | 收入增长指数 | >1.13 高增长公司操纵动机更强 |
| DEPI | 折旧率指数（去年÷今年） | >1.00 折旧变慢粉饰利润 |
| SGAI | 销管费用指数 | <1.00 费用率降过快需验证真实性 |
| TATA | 总应计÷总资产 | >0.03 权重最大的单一变量 |
| LVGI | 杠杆指数 | >1.00 债务约束下动机上升 |

规则：M-Score 只作筛查不作定罪；进入嫌疑区 → 逐变量找业务解释，找不到 → 第 5 节评级封顶 C。为什么：模型对高增长公司有系统性误报，但"解释不了"本身就是信息。

### 2.2 收入确认激进信号

| 信号 | 检查方法 | 危险判定 |
|---|---|---|
| Bill-and-hold | 附注搜索 bill-and-hold / 已开票未发货；问答是否回避交付时点 | 存在即黄旗；占收入 >2% 红旗 |
| 渠道压货 | 经销商库存周数、季度末集中发货（Q4 末收入占比异常）、返利/退货政策放宽 | 渠道库存增速 > 终端销售增速连续 2 季 |
| 关联方收入 | 关联交易附注：收入占比、定价依据、应收账期 | 关联方收入占比 >5% 且账期长于第三方 |
| 完工百分比/长周期合同 | 合同资产（未开票应收）增速 vs 收入增速 | 合同资产增速超收入 >15pct |
| 总额 vs 净额 | 平台/代理类公司确认口径是否变更 | 口径变更当季贡献增速须剔除重算 |

### 2.3 资本化 vs 费用化

- 检查三处：研发资本化率（资本化研发÷总研发）、软件/网站开发资本化、客户获取成本（合同成本资产）摊销期。
- 硬性规则：资本化率同比上升且该上升解释了 >20% 的利润增长 → 按全费用化重算一版 EPS 并在正文并列展示。为什么：资本化是把今天的费用寄给明天，重算才能看到真实盈利能力。
- 摊销期长于客户留存期/合同期 → 直接红旗。

### 2.4 一次性项目的"经常性"检测

规则：任何标签为重组、减值、诉讼、退出成本的项目，**连续 4 个季度及以上出现 = 经常性经营成本**，估值时全额计回利润。为什么：年年重组的公司，重组就是它的商业模式。

### 2.5 审计与内控

| 检查项 | 危险信号 |
|---|---|
| 审计意见 | 非标意见、强调事项段、持续经营疑虑 → 评级封顶 D/C（视严重度） |
| 关键审计事项（KAM/CAM） | 与最小核查集报警项重合（如收入确认、准备金）→ 该项升级为严重 |
| 审计师变更 | 财年内更换、由大所换小所、"意见分歧"字样 → 红旗，写入第一章 |
| 审计费用 | 费用大幅下降但业务复杂度未降 → 黄旗 |
| 内控缺陷 | 重大缺陷（material weakness）未整改 → 评级封顶 C |
| CFO/审计委员会变动 | CFO 突然离职 + 任一核查项恶化 → 红旗组合 |

## 3. 现金流侦查

OCF 不是不可操纵的圣杯，只是操纵成本更高。

| 手法 | 识别方法 | 处理 |
|---|---|---|
| 应收保理/证券化 | 附注搜索 factoring / securitization / 应收转让；应收下降但收入未降 | 把保理额加回应收重算 DSO |
| 供应链金融（反向保理） | 附注/问答搜索 supply chain finance；应付激增且 DPO > 90 天异常 | 把该部分视为有息债务，同时修正 OCF |
| 应付拉长 | DPO 同比 +15 天以上且无采购结构解释 | 该部分 OCF 改善标注为"不可持续" |
| 税款/租金时点 | 递延纳税、政府补助到账时点集中在期末 | 剔除后看 underlying OCF |
| 营运资本季末冲刺 | 期末应付冲高、期初回落（对比 Q 内均值或下季回吐） | 连续出现 → 现金转化项直接判恶化 |

FCF 定义游戏（硬性规则：估值一律用**标准 FCF = OCF − 全部 Capex − 已资本化研发/合同成本**重算，不采用公司自定义）：
- 排除 SBC：SBC 是真实费用，回购对冲稀释的现金流出必须计入。为什么：不花现金不等于不花股东的钱。
- 排除租赁本金偿还：IFRS 16/ASC 842 下经营租赁本金在筹资活动，FCF 须手工扣回。
- 排除并购 earnout、重组现金支出："经常并购"的公司其 earnout 就是 Capex。
- "调整后 FCF"与标准 FCF 差异 > 20% → 差异桥必须进正文。

## 4. 资产负债表侦查

### 4.1 商誉与无形

- 商誉 + 无形占总资产 > 40% → 必查减值测试假设：CGU 划分、折现率、永续增速、预测收入 CAGR。
- 硬性规则：减值测试假设的收入 CAGR 高于本报告基准情景 → 在正文指出"账面商誉依赖比我们更乐观的假设"。为什么：这是管理层自己写下的、可对照的乐观度证据。
- headroom（可收回金额超账面的幅度）< 10% 且行业逆风 → 减值风险写入风险章。

### 4.2 存货结构

- 拆原材料/在产品/产成品三段增速：**产成品增速 > 收入增速 > 原材料增速 = 需求走弱**（做出来卖不掉）；原材料激增 + 产成品正常 = 备产扩张（中性偏多）。为什么：结构比总额诚实，总额可以用"备货"一词搪塞。
- 存货跌价准备计提率环比下降 + 产成品堆积 = 双重红旗。

### 4.3 或有负债与表外承诺

- 必读附注：诉讼与或有事项、担保、采购承诺（take-or-pay）、未合并实体（VIE/SPE）、经营租赁承诺总额。
- 硬性规则：或有负债潜在敞口 > 净利润 1 倍或净资产 10% → 写入第一章快照表下方风险行。
- 对外担保对象为关联方 → 直接红旗，进第 5 节评级。

## 5. 财报可信度等级（A/B/C/D）

评级基于第 1 节六项核查 + 第 2–4 节触发项，在第一章快照表中披露并注明"依据 forensic-accounting.md"。

| 等级 | 标准 | 否决规则 |
|---|---|---|
| A | 六项最小核查全过，且现金转化 OCF/NI > 90%（TTM），无任何红旗 | 无；财报可作为论点证据全额采信 |
| B | 1 项轻度恶化（触发阈值但未达严重线），其余全过 | 无否决；恶化项列入下季监控指标 |
| C | ≥2 项恶化，或任 1 项严重（应计 TTM > +10%、M-Score 进嫌疑区、内控重大缺陷、审计强调事项） | 估值结论**强制降一档**（低估→合理，合理→高估）；禁用"低估"标签及任何买入类建议；EPS beat 不得计入正面证据权重 |
| D | 涉嫌操纵信号：M-Score 严重超标 + 多项同向、审计非标/持续经营疑虑、监管调查/问询涉财务真实性、关联方输送证据 | 只允许"回避/卖出"结论；任何 beat 不得作为看多证据；估值区间仅作参考并标注"基于不可信报表"；解除 D 级需连续 2 季核查通过 + 触发事由消除 |

硬性规则：
1. 评级只能由核查结果驱动，不许因"公司知名/管理层口碑"上调。为什么：安然和瑞幸出事前口碑都很好。
2. 评级下调必须写明触发项和数值；上调必须写明前触发项如何消除。为什么：评级变动本身是可追踪预测，按 `output-format.md` §5 登记。
3. C/D 级的否决优先级高于估值方法输出——模型算出再大的上行空间也不解锁买入标签。为什么：垃圾进垃圾出，输入不可信时输出精度是假象。
4. 评级与置信度自评表（`output-format.md` §4）中"财报可信度"行必须一致。

## 6. 行业例外

应计比率、DSO、存货类指标假设"收入—应收—现金"的工业企业循环，以下行业不适用，用替代指标保持同等深度：

| 行业 | 不适用项 | 替代核查 |
|---|---|---|
| 银行 | 应计比率、DSO、存货、OCF/NI | 拨备覆盖率与不良生成率环比、Stage 2/3 贷款迁徙、净息差 vs 生息资产增速背离、AOCI 未实现损失占核心资本、贷存比 |
| 保险 | 应计比率、现金转化 | 准备金充足性（准备金发展 favorable/adverse development 连续方向）、综合成本率拆分（赔付率 vs 费用率）、投资收益中已实现 vs 未实现占比、退保率 |
| REIT | NI 基现金转化、存货 | FFO/AFFO 对账逐项检查（尤其经常性 Capex 是否压低）、Same-store NOI vs 整体 NOI 背离、资本化利息、出租率 vs 租金坪效 |
| 券商/资管 | DSO、存货 | 公允价值层级（Level 3 资产占比及环比）、自营 vs 代客口径、管理费 vs 业绩报酬结构 |
| 公用事业 | 应计比率（监管资产扭曲） | 监管资产/负债变动、允许 ROE vs 实际 ROE、购电成本传导时滞 |

规则：金融类公司的可信度评级改由上表替代指标 + 第 2.5 节审计内控 + 第 4.3 节或有负债驱动，评级标准和否决规则不变。为什么：指标可以换，纪律不能换。
